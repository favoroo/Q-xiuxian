# 使用指南：素材落地、Godot 导入、能力边界

## 素材落地约定（全项目统一）

```
assets_raw/                  ← 生成原稿区（有 .gdignore，Godot 不扫描）
├── style/STYLE.md           ← 项目风格档案：STYLE_PREFIX / 锚图 / VOICES 音色表（生成前必读）
├── style/anchor*.jpg        ← 风格锚图、角色设定图
├── images/                  ← 生图原稿与透明 PNG（语义命名：icon_potion_red.png）
├── voice/                   ← 台词 WAV（命名：vo_<角色>_<场景>_<序号>.wav）
├── music/                   ← BGM MP3（命名：bgm_<场景>_<情绪>.mp3）
└── manifest.jsonl           ← 生成台账（脚本自动写）：ts/kind/model/prompt/refs/output
```

- **先查 manifest 再生成**：`grep "关键词" assets_raw/manifest.jsonl`，
  已有相似素材优先复用或用参考图编辑，不要重复烧配额。
- 精选过的成品才进 Godot 可见目录（如 `assets/art/`、`assets/audio/`），
  `assets_raw/` 永远只当底稿库。

## Godot 导入注意（T1 = Godot 4.7）

- **纹理过滤**：若 STYLE.md 定的是像素风，项目设置 → Rendering → 纹理过滤必须改
  Nearest（否则像素图被平滑糊掉）；其他位画风保持默认 Linear。项目已设
  `textures/canvas_textures/default_texture_filter=0`（Nearest）；新增素材不要在单个
  `.import` 里把纹理过滤覆盖回 Linear。
- **整数缩放与像素完美渲染**：像素图静止基准 scale 取整数倍（1×/2×），图集单元格已是
  192px，按需 2× 显示，保证像素网格整齐。允许非整数的例外：瞬态 juice tween（弹出/
  脉冲/挥砍放大）、相机平滑 zoom 与 `zoom_punch`（`SmoothCamera._base_zoom=1.2`，刻意
  为手感）——短暂动效不破坏静止时的像素整洁。代码里 `resize`/`scale_texture` 一律
  最近邻，禁用双线性/Lanczos（同下文「角色动作帧规范」第 3 条 NEAREST/二值化规则）。
- **角色差分/转身表**：用 `--grid` 一次一表再切分，游戏内配合程序动画（tween 位移/
  缩放/闪白）合成动效，不追求逐帧动画。
- **BGM 循环**：MP3 导入参数勾 loop；音效 WAV 一次性播放不用勾。
- **导入覆盖**：同一素材生成多版挑选时，文件名带 `_v2/_v3`，别直接覆盖已导入文件
  （Godot 会缓存 .import）。
- 大图（1408×768）进场景前按需缩到目标尺寸，省显存。

所有模板都以 STYLE.md 的 `STYLE_PREFIX` 开头 —— 该档案为空时先走风格锚定工作流。

## 角色动作帧规范与拼装标准（借鉴 pixel-asset-master 规范）

在生成与拼装角色行走/奔跑 8 方向序列帧（`tools/build_run8_atlas.py`）时，必须严格遵守以下 5 条硬性约束，防止角色出现“悬浮、一抖一抖、滑冰”现象：

1. **统一地面水平锚点（Fixed Ground Baseline）**：
   - **绝对禁止单帧独立 `crop(bbox)` 后贴底**。若对每帧分别底对齐，会导致抬腿帧（包围盒变矮）时整个身体被错误地向下拖拽，帧间头部剧烈窜动。
   - 必须以整条 1×5 序列的统一地平线为 Y 轴锚点：**支撑脚（Contact）踩死在地平线上，迈步腾空脚（Passing）自然离地**。进入图集后，地面线精确映射至单元格的 `cfg["base"]`。
2. **躯干重心水平对齐（Torso Centroid Alignment）**：
   - 水平 X 轴严禁使用整图包围盒中心 `(x1+x2)/2` 对齐，否则当单手兵器、甩袖或尾巴伸缩时，会带动整个身体左右筛糠式摇摆。
   - 必须取躯干/头部核心高度（15%~65%）的像素重心对齐至单元格中轴 `CX=96`，保证脊柱与头部稳定。
3. **纯净二值化 Alpha 与孤点清洗（Hard Alpha & Orphan Clean）**：
   - 严禁使用双线性/Lanczos 插值缩放像素图，必须使用最近邻（`Image.NEAREST`）。
   - 透明通道必须二值化（Alpha 介于 1~254 的半透明边缘在逐帧播放时会造成严重的“爬虫感”与轮廓频闪）。
   - 执行 4 邻域孤立像素清理，杜绝散落在角色四周的单像素杂点。
4. **程序动画协同（Code-Frame Synchronicity）**：
   - 当序列帧已具备迈腿动作时，代码层（`RunMotion.gd`）禁止叠加大幅整身 Y 轴抛起位移（`LIFT` 保持 ≤ 1.0px），确保双脚与地面阴影（Shadow）紧密贴合。
   - 待机 Idle 必须双脚钉牢地面，停用整身上下漂移位移（`offset.y = sin(...)`），改用轻微呼吸缩放（1.0%~1.2%）。
5. **帧率与时序标准（FPS Standards）**：
   - 4 帧奔跑动画推荐播放帧率：`10.0 ~ 12.0 fps`（使两步动作在 0.35~0.4 秒内完成，轻快紧凑，消除慢速幻灯片顿挫感）。
   - 变向切换动画时保留 `frame` 与 `frame_progress`，保持步态周期连续不重置。

## 能力边界（别绕弯路）

| 需求 | 行不行 | 替代方案 |
|---|---|---|
| 透明底 PNG | ✅ 走 `--keyout` 品红管线 | 主体含品红/粉色时换纯绿底+手动改 keyout.py |
| 逐帧动画序列（走路循环等） | ❌ 模型生成不了多帧一致的动画 | 静态图 + 程序化动画（tween 挤压/闪白/浮动）；或免费素材包 |
| 音效 SFX（枪声/爆炸/UI 音） | ❌ 无 SFX 模型 | jsfxr（网页生成复古音效）、freesound.org、Kenney 音频包（CC0） |
| 像素级精确的 tilemap 素材 | ⚠️ 风格能像，网格对齐不稳 | 走 tilemap 素材包（itch.io/kenney），或生成后手动修 |
| 中文语音 | ✅ | gen_voice.sh |
| 商用合规 | ⚠️ | 生成图带 SynthID/C2PA 隐形水印；各平台条款自查；别要求在世画师风格 |

## 故障排查

| 症状 | 原因 | 处理 |
|---|---|---|
| curl HTTP 000 | 本机 ALL_PROXY 指向失效代理 | 所有 curl 加 `--noproxy '*'`（脚本已内置） |
| 响应无图/无音频 | 模型偶发只回文本 | 脚本自动重试 2 次；仍失败换措辞重试 |
| 抠图边缘有品红晕 | JPEG 压缩溢色重 | 提高 keyout.py 的 hi 阈值（如 130）重跑 raw.jpg |
| 图完全没抠透 | 品红区域占比 < 4% 未触发裁剪 | 手动跑 `keyout.py raw.jpg out.png` |
| TTS 把指令读出来 | 指令没用方括号括起来（实测"用XX的语气说："会被朗读） | 用 `--style`（脚本自动转方括号）；手动调 API 时写成 `[音色描述]台词` |

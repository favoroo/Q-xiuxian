# 剑士（Swordsman）

> 修仙题材的俯视角自动攻击幸存者游戏。选角色、配法器、扛过 20 波妖魔，悟道加点、金币阁淘宝，一战到底。
> 当前版本 `v0.0.32`（Android，包名 `com.favo.qxiuxian`）。

## 玩法

- **自动战斗**：角色手持法器自动索敌攻击，你只管走位与构筑。
- **20 波生存**：波次推进，妖魔渐强，撑到 `VICTORY_WAVE` 即胜。
- **悟道加点**：每回合后从 5 个候选中选成长方向，1 次免费刷新。
- **金币阁**：回合间用金币购买法器、道具与灵兽，构筑你的流派。
- **流派构筑**：多角色、多法器、多道具、多灵兽，自由组合出不同的战斗风格。

## 平台与引擎

- **引擎**：Godot 4.7（Forward+ 渲染）/ GDScript / Jolt 物理
- **平台**：Android APK（arm64-v8a）
- **桌面调试**：960×540

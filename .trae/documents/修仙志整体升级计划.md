# 修仙志整体升级计划

## Context

修仙志（CareerDialog）目前只有全局生涯统计 + 成就列表 + 最近 10 条战报，缺乏「角色维度」的成长沉淀与奖励钩子。本次升级目标：

1. **每角色档案**：渡劫成功次数（通关 20 波）、无尽模式最大关数、最高危险度、单角色最高斩妖
2. **角色里程碑奖励**：每角色 4 档（渡劫 1/3/5/10 次），称号徽章自动点亮 + 灵石囊需手动领取（兑入下局开局灵石），领取有仪式感
3. **渡劫实录**：每次渡劫成功的完整战报快照——上阵法器（图标+星级）、法宝列表、关键属性、击杀/波数/时长，点击行展开查看
4. **成就感增强**：结算弹窗「新纪录」标签、主菜单修仙志入口红点、角色称号徽章展示

奖励设计理由：称号纯展示零平衡影响；灵石囊是一次性消耗品，量级小（30/60/100/200），不破坏「零局外数值膨胀」底线，且比纯展示奖励更有领取动力。不需要新美术素材。

## 改动清单

### 1. `scripts/data/AchievementData.gd`（纯 static，不动 GameBalance）

- 新增 `CULTIVATOR_MILESTONES: Array[Dictionary]`：`{id:"<cid>_<tier>", cultivator_id, wins: 1/3/5/10, title: "初证道果/小道有成/道基稳固/渡劫金丹", stones: 30/60/100/200}`
- 纯函数：
  - `title_for_wins(wins) -> String`（最高已达标档位称号）
  - `milestones_of(cid) -> Array[Dictionary]`
  - `is_milestone_claimable(mile_def, wins, claimed_arr) -> bool`
  - `any_claimable(records, claimed) -> bool`（供红点）

### 2. `scripts/autoload/GameManager.gd`

- 新增状态（不进 reset_run）：`cultivator_records: Dictionary`（`{cid: {runs, wins, endless_best_wave, best_kills}}`）、`victory_log: Array`（cap 50）、`claimed_milestones: Array`、`stone_purse: int = 0`、`last_run_new_records: Array`
- `start_run()`：开头调用新私有 `_redeem_stone_purse()` —— `spirit_stones += stone_purse`、清零、`announcement_triggered.emit("✦ 灵石囊生效 · 开局灵石 +N ✦")`
- 新增 `has_claimable_rewards() -> bool`（红点查询）

### 3. `scripts/autoload/ProgressStore.gd`（SAVE_VERSION 升 2，旧档 get_value 默认值兜底，零迁移）

- `load_into` / `save_from`：补读写 4 个新键（cultivator_records / victory_log / claimed_milestones / stone_purse）
- `record_run_and_check_achievements` 重构：
  - **无尽终局分支**（`gm.endless_mode and not victory`）：只更新该角色 `endless_best_wave = max(wave_number)`、`best_kills`、生涯 `best_wave`，push 一条 `"endless": true` 战报进 run_history；**跳过 total_runs/total_kills/total_stones/total_time 累加**（victory 时已计过，顺手修掉现有双计问题）；落盘后 return
  - **正常分支**：累加 `cultivator_records[cid]`（runs/wins/best_kills）；victory 时生成快照 push 进 victory_log（新到旧，cap 50）：
    - 字段：`cid / danger / wave / kills / level / time / datetime(Time.get_datetime_string_from_system()) / weapons:[{name,star,icon,is_drone}] / items:[{name,icon}](经 ItemData.get_def 映射) / stats:{armor, dodge, crit_rate, hp_max(player.max_health，节点无效则 0), harvest, luck, stones}`
    - **必须剔除 `get_weapons_summary()` 返回里的 `"node"` 键**（ConfigFile 序列化 Node 会炸档）
  - 快照时机安全：`trigger_game_over` 内同步执行，先于 `get_tree().paused` 与场景重载，胜利/死亡两路径 player 均有效（已核实 Player.gd:787 / WaveSpawner.gd:179）
  - **新纪录检测**：结算前先取旧值，比较生成 `last_run_new_records`（如「生涯新纪录 · 斩妖 312」「道统新纪录 · 无尽第 25 波」「道统首胜 · 石岳」）
  - 里程碑达标只入提示，**不自动发灵石**（手动领取）

  - 未解锁角色：置灰 + 「这是什么」DetailTip 显示解锁条件（AchievementData.cultivator_unlock_achievement 反查）
  - **领取控件必须 PanelContainer + GameStyle.tap()**（铁律：滚动区内禁 Button）；文案「领 N 灵石」，点击 → `claimed_milestones.append` + `stone_purse += N` + 落盘 + AudioManager 按钮 sfx + 刷新本行（重复点击幂等）
